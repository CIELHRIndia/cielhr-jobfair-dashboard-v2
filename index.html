🧹 Data management

Super Admin cleanup tools for test/demo data. These actions do not delete the GitHub event catalogue, Apps Script API token, deployment, Gmail trigger or Drive folder structure.

Clear Candidate Community

Removes all verified Community candidate records from this browser and the approved candidate data stored by the Gmail + Drive backend. Event catalogue, assignments, registration status, actual footfall and workflow state are preserved.

Reset one event

Returns one selected event to New, clears its assignee, actual footfall, pending/verified candidates for that event, and removes that event's Gmail + Drive workflow record/files.

Clear all test workflow data

Clears all local Community/Pending test records, resets every event to New, removes all Apps Script assignment workflow properties and trashes generated proof/submission/processed files. The event catalogue and system configuration remain intact.
